# 在 Mac 桌面用 Übersicht 回顾划线

将 [Übersicht](https://tracesof.net/uebersicht/) 放进「应用程序」，从 [GitHub Releases](https://github.com/ma-tie/WeReadHighlights/releases/latest) 下载并解压 Mac ZIP，然后双击解压目录里的 `Install.command`。安装脚本会使用 Übersicht 自带的运行环境并启动应用。也可以从源码仓库根目录运行：

```sh
macos/uebersicht/Install.command
```

桌面左上角会显示卡片。点卡片右上角的齿轮，再点「配置 API Key」，在弹出的窗口里粘贴微信读书的 `wrk-` API Key。钥匙串已有配置时会继续使用。设置好后，鼠标移到卡片上才会显示齿轮。

把鼠标移到卡片上，按住右下角的角标拖动即可调整大小。松开后自动保存尺寸并重新排版。宽度范围为 156–800 px，高度范围为 120–600 px。「设置」里可选择系统字体、宋体或楷体优先。正文按可用宽度换行，超出可用高度时显示省略号。默认使用 macOS 系统字体。从旧版更新时，旧的「楷体优先」设置会切换到新的默认字体，可在齿轮里重新选择。

随机更新周期可选 1、2、3、4、6、8、12 或 24 小时。拖动字号滑块可同时调整正文、书名和作者。字号可在 50% 到 250% 之间调节，步长为 0.5 个百分点，松手后保留所选字号。可选择是否显示作者。点「换一句划线」可以在当前时段内重新抽取。

也可以手动在「钥匙串访问」的登录钥匙串里添加 `WeReadHighlights` 密码项目，账户名称填 `WeRead API Key`。

组件每分钟检查一次配置。若系统提示 `security` 读取刚创建的项目，可以允许这次读取。API Key 由本地辅助脚本读取并用于请求微信读书；桌面组件只接收划线数据。关闭 Übersicht 会隐藏卡片。

点击真实划线卡片会用默认浏览器打开微信读书。普通书籍有章节和划线位置时，网页阅读器会尝试滚动到该段文字。只有部分位置数据时，会打开章节或书籍；无法生成阅读器链接时，按书名搜索。

组件安装时会打包 [共享 JS 源文件](../../ios/WeReadHighlights.js) 和 Mac 适配层。改动共享脚本后重新运行安装命令，即可更新桌面卡片。若使用了自定义组件目录，可用 Node 运行 `install.cjs` 并传入该目录。按住划线卡片拖动即可调整位置，松开后自动保存，重新启动后继续使用。单击卡片仍会打开阅读链接；齿轮和设置控件不参与拖动。

在齿轮的「颜色与背景」中可以单独调整背景渐变、正文、书名、作者、装饰线、分隔线和引号颜色。可选择本机 JPG、PNG 或 WebP 图片（20 MB 以内）作为背景；图片会压缩保存于本机，默认居中裁切。背景遮罩使用所选背景渐变，可调整深浅以保证文字清晰。可移除图片或恢复默认颜色与背景，更新安装会保留设置。

选好图片后，打开「裁切背景」。预览按当前卡片的宽高显示。按住预览拖动图片，并用缩放滑块调整构图，最后点击「保存裁切」。调整卡片尺寸时，会按新的宽高重新应用已保存的构图。

勾选颜色项旁的「透明」可隐藏对应元素。渐变的两个端点都设为透明，整条渐变才会消失。取消勾选会恢复该项的默认颜色。
