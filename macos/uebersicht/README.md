# 在 Mac 桌面用 Übersicht 回顾划线

将 [Übersicht](https://tracesof.net/uebersicht/) 放进「应用程序」，从 [GitHub Releases](https://github.com/ma-tie/WeReadHighlights/releases/latest) 下载并解压 Mac ZIP，然后双击解压目录里的 `Install.command`。安装脚本会使用 Übersicht 自带的运行环境并启动应用。也可以从源码仓库根目录运行：

```sh
macos/uebersicht/Install.command
```

桌面左上角会显示卡片。点卡片右上角的齿轮，再点「配置 API Key」，在弹出的窗口里粘贴微信读书的 `wrk-` API Key。钥匙串已有配置时会继续使用。设置好后，鼠标移到卡片上才会显示齿轮。

「设置」里可以切换小、中、大号，并选择系统字体、宋体或楷体优先。小、中、大号使用共享脚本的三套布局。默认使用 macOS 系统字体。从旧版更新时，旧的「楷体优先」设置会切换到新的默认字体，可在齿轮里重新选择。

随机更新周期可选 1、2、3、4、6、8、12 或 24 小时。正文字号有紧凑、标准和舒展三档。中号、大号可以选择是否显示作者，小号只显示书名。点「换一句划线」可以在当前时段内重新抽取。

也可以手动在「钥匙串访问」的登录钥匙串里添加 `WeReadHighlights` 密码项目，账户名称填 `WeRead API Key`。

组件每分钟检查一次配置。若系统提示 `security` 读取刚创建的项目，可以允许这次读取。API Key 由本地辅助脚本读取并用于请求微信读书；桌面组件只接收划线数据。关闭 Übersicht 会隐藏卡片。

点击真实划线卡片会用默认浏览器打开微信读书。普通书籍有章节和划线位置时，网页阅读器会尝试滚动到该段文字。只有部分位置数据时，会打开章节或书籍；无法生成阅读器链接时，按书名搜索。

组件安装时会打包 [共享 JS 源文件](../../ios/WeReadHighlights.js) 和 Mac 适配层。改动共享脚本后重新运行安装命令，即可更新桌面卡片。若使用了自定义组件目录，可用 Node 运行 `install.cjs` 并传入该目录。想调整位置，可修改 `widget.jsx` 的 `top` 和 `left`，然后重新安装。
